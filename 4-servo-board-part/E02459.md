# 4.7. E02459. (O 轴) 编码器断开或接触故障 (电机开启状态)

### 1. 概述

伺服板与编码器进行串行通信以控制伺服电机，并定期接收编码器数据；当编码器与伺服板之间的通信不稳定或根本未接收到信号时，会出现此错误。

编码器与伺服板之间的通信不稳定或根本未接收到信号的情况主要可能由于编码器电缆的断开或接触不良造成。

### 2. 原因和检查

{% hint style="info" %}

(1)	检查编码器供电电压

(2)	检查编码器接线

(3)	进行伺服板的更换测试

(4)	进行电机（编码器）的更换测试

(5)	在完成措施后检查接线的通信状态

{% endhint %}

有关详细检查方法，请参阅 "E02450 (O 轴) 无编码器响应"。
